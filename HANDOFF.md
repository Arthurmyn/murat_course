# Передача проекта — инструкция

В архиве два раздела:
- **site/** — сам сайт (это то, что нужно задеплоить)
- **landing-design/** — исходник дизайн-макета (не обязателен для сайта, оставлен для справки)

## 1. Создать свой GitHub-аккаунт и репозиторий

1. Зарегистрироваться на [github.com](https://github.com) (если аккаунта ещё нет)
2. Нажать **New repository** (зелёная кнопка справа сверху или на github.com/new)
3. Название — например `kost-controller-course`. Оставить **Private**, если не хотите, чтобы код видели посторонние. Ничего больше не отмечать (не добавлять README/.gitignore — они уже есть в архиве)
4. Нажать **Create repository**

## 2. Загрузить файлы

Самый простой способ — без установки программ:

1. На странице нового репозитория нажать **uploading an existing file**
2. Разархивировать присланный zip-файл на компьютере
3. Перетащить в браузер содержимое папки (README.md, landing-design/, site/) — можно всё сразу
4. Внизу нажать **Commit changes**

## 3. Создать свой Vercel-аккаунт и задеплоить

1. Зарегистрироваться на [vercel.com](https://vercel.com) — проще всего через кнопку **Continue with GitHub**, тогда аккаунты сразу свяжутся
2. Нажать **Add New → Project**
3. Выбрать только что созданный репозиторий → **Import**
4. **Важно:** в настройках перед деплоем открыть **Root Directory** и указать `site` (сайт лежит в этой подпапке, не в корне)
5. Framework Preset — оставить **Other**
6. Нажать **Deploy**

Через минуту Vercel даст рабочую ссылку вида `что-то.vercel.app` — сайт уже живой.

## 4. Подключить домен course.restocalculator.kz

1. В проекте на Vercel: **Settings → Domains** → вписать `course.restocalculator.kz` → **Add**
2. Vercel покажет DNS-запись для добавления, обычно:
   - Type: **CNAME**
   - Name: `course`
   - Value: `cname.vercel-dns.com`
3. Добавить эту запись в DNS-панели, где управляется домен restocalculator.kz (у регистратора или в Tilda, смотря где сейчас настроен домен)
4. Подождать 10–30 минут — Vercel сам подтвердит домен и выпустит SSL-сертификат

## 5. Как редактировать тексты на сайте в будущем

Весь контент (программа курса, отзывы, цены, тексты) собирается из одного файла `site/build.py` — там простые списки текста в начале файла.

1. Открыть `site/build.py` в любом текстовом редакторе, изменить нужный текст
2. Запустить в терминале (находясь в папке `site`): `python3 build.py`
3. Это пересоздаст `site/index.html`
4. Загрузить обновлённый `index.html` в GitHub (кнопка **Add file → Upload files** в репозитории) — Vercel задеплоит изменения автоматически за минуту

Если такие правки будут делаться редко и без программиста — можно и напрямую редактировать `site/index.html` в текстовом редакторе (просто чуть менее удобно, чем через build.py).
